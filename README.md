# Feature-Extraction-Project


Anime dataset analysis and feature extraction using Python and Pandas.

## Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

## Files
- `FeatureExtraction.ipynb` — Main Jupyter Notebook
- `anime.csv` — Dataset

## How to Run
1. Download the repository
2. Open `FeatureExtraction.ipynb` in Jupyter Notebook
3. Make sure `anime.csv` is in the same folder
4. Run the notebook cells
